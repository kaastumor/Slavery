## Findings and limits

The guide routes the active Indus work to a historical evidence gate, retains a
qualified or inconclusive result as valid, and gives the next session a concrete
source reconciliation action. The three gates remain separate, and the handoff
fields require evidence, limits, attack consequences and the next decision-relevant
action. No claim about 5.6 reliability or external researcher value is warranted.

This was a same-agent static replay against representative scenarios. It did not
benchmark models, exercise a real external researcher, or run the new branch's CI.
The first live continuation should check for duplicate work, lost access limits,
wrong-gate routing and unnecessary CI dispatch; any failure should update D-091 and
the execution guide before widening the process.
