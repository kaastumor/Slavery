# Task capsule

Copy only the context needed for this bounded item. Resolve unknown prerequisites before
execution; do not copy complete conversations. Link the current authoritative owner and
pending PR/checkpoint. Repeat critical rules in the capsule even when AGENTS contains them.

- Constraints:
- Explicit non-goals:
- Files, sources, or systems in scope:
- Authority granted:
- Actions requiring approval:
- Implementation or research stages:
- Done when:

- Escalate when:

## Execution envelope

- Task ID, contract version, input revision, lane and current owner:
- Project mode and accepted mandate (separate from surface, model and run status):
- Requested / actual model and effort (UNKNOWN if unavailable):
- Timebox; maximum items; usage ceiling and telemetry availability:
- Durable output/checkpoint location and privacy classification:
- Existing packet/PR to resume; deduplication key; dependency:
- Critical constraints repeated: project evidence/privacy rules; no unapproved merge,
  deploy, publish, deletion, production/credential change, purchase or external contact.
- Scope overlap/ownership check and capability preflight:
- Retry/stop rule; unresolved approval or missing prerequisite:

New scheduled research defaults to 20 minutes and one item. Follow the project's canonical
operating policy. Do not inflate a discovery task into implementation or relax acceptance
because a tool, credential or stronger model is unavailable.

## Completion receipt

Record outcome/disposition; actual changed files or evidence references; checks run and
results; skipped checks with reasons; limitations; elapsed time; actual usage or UNKNOWN;
and next exact action. Distinguish READY_FOR_REVIEW, RECONCILIATION_PENDING, CHECKPOINTED,
BLOCKED and NO_CHANGE from accepted/merged state. Include input/output refs and a consumer
acknowledgment only after verifying it. Keep private evidence in its permitted private owner.

Review the diff/output against the capsule and user-visible outcome. A passing test,
persuasive summary or self-review is not proof of independent validation.
