# Backlog moved

The canonical execution queue is now the repository-root **`BACKLOG.md`**.

This file is retained only so older documentation links do not create a second competing backlog.

- `BACKLOG.md` for current priority/order, blockers, next tasks, and recently completed milestones;
- GitHub issues for detailed task discussion and acceptance history;
- `docs/08_DECISIONS_LOG.md` and the canonical methodology/architecture docs for durable project rules.
