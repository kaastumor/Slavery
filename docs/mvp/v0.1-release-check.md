# Historical Slavery Atlas — MVP v0.1 Technical Release Check

**Gate:** #182  
**Parent:** #174  
**Date:** 2026-09-24  
**Disposition:** **TECHNICAL_MVP_CANDIDATE**  
**Canonical historical release:** **v0.6.1 remains unchanged**

This is a technical delivery gate only. It does **not** claim canonical publication, independent historical review, or sponsor/browser usability acceptance.

## Candidate that passed the gate

The smallest surviving Atlas core is now materialized as:

> **deterministic R1 candidate bundle + neutral world map + explicit research/geometry state + compact evidence register + discrete temporal guards**

The default web path:
- is Vite + TypeScript + MapLibre;
- consumes the generated static R1 candidate bundle;
- does not require the live Atlas evidence API;
- does not use Supabase/database access for candidate evidence;
- fails closed rather than falling back to legacy historical data.

### Research-state / non-absence semantics

PASS.

The MVP distinguishes:
- reviewed bounded-supported;
- reviewed inconclusive;
- planned/unresearched;
- held;
- C0-only;
- geometry unresolved.

Research coverage is categorical, not an intensity scale.

Unresearched, held, inconclusive and unresolved geometry do not become historical absence.

### Evidence register

PASS.

Reviewed records expose:
- strongest bounded proposition;
- required abstention;
- evidence locus;
- inference extent;
- law/practice and network/territorial notes where present;
- exact source/version reference;
- source locator;
- source-family / independence-group label;
- review state;
- language/access limitation;
- coverage confidence;
- geometry state.

Targets without reviewed C1 packets expose only permitted research/identity/frame state and an explicit non-absence warning.

### Temporal rendering

PASS.

Navigation is now over discrete frozen research anchors rather than continuous annual truth.

R1.6 precision states remain visible:
- exact cross-section;
- period-level;
- near-anchor / approximate;
- selected-year unknown;
- aggregate / no single territorial state;
- unassessed because subject research was not performed.

BCE conversion is explicit:
- frozen source-native `-500` = display **500 BCE**;
- Atlas astronomical internal year = `-499`;
- source-native `-1` = 1 BCE = Atlas internal `0`.

### Geometry / map behavior

PASS WITH EXPLICIT LIMITATION.

All 77 target geometries currently remain `unresolved_no_geometry`.

That is accepted because the MVP refuses to manufacture historical polygons, sampling points or modern proxies merely to populate the map.

Neutral land remains the universal geographic context layer.

### Static/no-backend operation

PASS WITH EXPLICIT LIMITATION.

Historical evidence data is static/read-only and requires no live evidence API, backend or database.

**External neutral-land asset:** the current MVP still fetches the public Natural Earth 110m land GeoJSON from `raw.githubusercontent.com/nvkelso/natural-earth-vector` at runtime.

This is not a historical evidence dependency and does not change claims, but it means the neutral land outline is not yet fully self-contained/offline. A later release decision may vendor this ordinary base asset if deployment reliability requires it; that does not justify backend infrastructure.

## Known limitations carried into sponsor review

1. **All target geometry unresolved.** The MVP is presently a neutral map + evidence register, not a mature historical-boundary map.
2. **External neutral-land asset.** Neutral Natural Earth land is runtime-fetched rather than vendored.
3. **Sponsor/browser usability acceptance remains pending.** Automated technical checks do not substitute for a human opening and using the Atlas.
4. **No independent historical review.** The 19 C1 rows have internal adversarial replay only.
5. **Uneven language/access coverage.** Row-level limitations remain part of the evidence packet.
6. **58/77 targets are not reviewed C1 subject claims.** They remain visible as unresearched/held/C0 research state, never absence.
7. **No public/canonical promotion yet.** The existing public preview remains a non-canonical legacy demonstration until an explicit R1.8 decision.
8. **No convenience features have been earned yet.** Search, richer timeline, source graph and cross-case comparison remain discovery questions.

## Gate conclusion

**TECHNICAL_MVP_CANDIDATE**

The project has reached the intended small core without reopening the discarded platform:
- no new backend;
- no database migration;
- no auth;
- no search/graph infrastructure;
- no frontend framework replacement;
- no new historical research;
- no new P0–P4/intensity derivation.

The next release decision is **R1.8: publish / hold / rework**, informed by sponsor usability review.

The post-MVP feature lane may now run bounded discovery experiments. Discovery results do not authorize production feature implementation.
