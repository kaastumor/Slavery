## Attacks and dispositions

| Attack | Disposition | Finding / repair |
| --- | --- | --- |
| Case selection gives Atlas a home-field advantage | **revise** | All three original cases directly stress distinctions the Atlas was built to preserve: regime continuity, law/practice, and network/territory. Replace Q1 with a category-heavy, low-map-value negative-control case. |
| Baseline is quietly crippled | **revise** | “Prose notes + source table” is too narrow. Arm A may use any competent ordinary tool already allowed by the charter: spreadsheet/table, simple timeline, QGIS/static map, nodegoat-style organization, ordinary search, and a strong general model when useful. It may not be forced to remain text-only. |
| Same model cannot independently benchmark its own reasoning | **revise** | Do not claim independent cognitive-performance or wall-clock evidence. The experiment evaluates **artifact affordances and error behavior** from a shared evidence packet. Research discovery performance is not the target; HC-003 already found parity there. |
| Sequential A→B→C lets later arms benefit from earlier thinking | **survives with constraint** | This is unavoidable for one-session execution. Mitigation: freeze the same evidence packet first, preserve A before translation, prohibit new evidence in B/C, and evaluate fixed probes against the frozen artifacts. |
| Documentation volume can masquerade as value | **revise** | Extra fields or longer text do not count. A gain counts only if it changes recoverability, prevents a pre-specified error, or enables a correct comparison that is materially harder in the smaller artifact. |
| Success criteria are too soft | **revise** | Use per-probe states: **direct**, **traceable**, **ambiguous/omitted**, **misleading**. A material B-over-A or C-over-B gain requires an improvement on at least two critical probes in at least two cases, with no new misleading result. |
| Map novelty/aesthetics can bias C | **revise** | C gets no credit for visual appeal or faster scanning alone. It must improve a probe state, reveal a correct temporal/spatial relation, or prevent a concrete inference error. |
| Source-access asymmetry | **survives** | Shared frozen evidence packet already prevents later arms from using better sources. Make the rule explicit and auditable in each case folder. |
| The experiment may be impossible to falsify because every distinction is “valuable” by definition | **revise** | Add a negative-control case where the expected result is that Atlas structure and especially a map may add little or no value. Parity is a successful experimental outcome. |
| Three cases may still be too small to generalize globally | **survives with limitation** | This is a discrimination pilot, not validation of global usefulness. A positive result may authorize at most one further bounded test; it cannot establish universal value. |
| Research-quality differences could dominate representation differences | **survives with constraint** | Each case must meet a minimum evidence package before comparison: at least one specialist synthesis/interpretation source, one independent corroborating source or bounded primary/source-native item when feasible, and explicit counter/limiting evidence check. |
| “Effort/time” cannot be measured reliably in this run | **revise** | Remove elapsed-time claims. Record representation overhead using observable artifact complexity: number of source records, claims/notes, cross-links, and bespoke code/files required. |

## Case revision

Original Q1 is withdrawn **before evidence collection**:

> Inca `mit'a` vs colonial Potosí `mita` continuity.

Reason: useful, but strongly tailored to the Atlas's known temporal/spatial semantics and therefore a poor negative control.

Revised Q1:

> **Mexica / Aztec central Mexico, c. 1400–1521:** What can a responsible synthesis say about `tlacotin`/enslaved or dependent statuses, and which aspects should remain category-qualified rather than flattened into a modern slavery label?

Why this is adversarial to the Atlas hypothesis:
- the hard work is terminological and historiographical rather than cartographic;
- a conventional narrative may be superior;
- a map is expected to add little;
- the corpus structure only earns value if it preserves category limits/provenance without turning them into bureaucratic overhead.

Q2 (British India 1843) and Q3 (Genoese Black Sea network) remain because they test different surviving hypotheses.

## Revised experimental target

This run does **not** ask whether the same model becomes “better” after using the Atlas.

It asks:

> Given the same evidence, what information, caveats and inference boundaries are recoverable from (A) a competent ordinary research artifact, (B) the Atlas corpus/method representation, and (C) the smallest visual/query representation derived from B?

That narrower target is testable and matches D-062.

## Gate

The setup may proceed only with the revised protocol. No historical result is allowed to retroactively change the probes or material-advantage rule.
