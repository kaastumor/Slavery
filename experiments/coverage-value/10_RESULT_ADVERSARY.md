# COV-001 — Result Adversary

**Issue:** #148  
**Input:** frozen sample, frozen mini-index, B2 ordinary matrix, fixed-query evaluation, negative controls  
**Disposition:** **SURVIVES ONLY AFTER INTERPRETIVE SHRINK**

The preliminary 5/6 result is attacked below.

| Attack | Disposition | Finding |
| --- | --- | --- |
| The six tasks are index-shaped, so a structured index is almost guaranteed to win | **revise** | True in part. Do not interpret task wins as proof of a novel information system. The legitimate question is narrower: does preassembly make these recurring coverage questions directly answerable? Preserve only gains that alter recoverability/error behavior. |
| B2 is artificially weak because a normal spreadsheet could add status/law/network columns | **survives but shrinks contribution** | Correct: nothing here requires Atlas ontology or infrastructure. That does not erase corpus value; it means the successful artifact is essentially a curated flat table with disciplined columns. |
| Q4 terminology advantage is just an extra column | **revise** | Downgrade Q4 from material to **marginal/not counted**. A competent ordinary matrix could add a terminology note without adopting project-specific machinery. |
| Q1 overview already works in B2 | **survives** | The preliminary evaluation correctly counted Q1 as parity. |
| Same model researched and evaluated the artifacts | **survives with limitation** | This invalidates claims about independent cognitive performance. Most judged differences are deterministic artifact properties (field present/absent; aggregation direct/reconstructive), but independent-user value remains unproven. |
| Direct/adjacent Cambridge/Palgrave coding is subjective | **survives with caution** | It is still useful as an explicit reviewed coverage judgment, but it is not an objective bibliographic completeness metric. Q5 can count only as bounded coverage-index value. |
| English/digital-access bias may masquerade as global research gaps | **survives with scope limit** | Rows explicitly say the packet is English-accessible and non-exhaustive. The index represents the declared research process, not world historiography. Never publish “none” as “no scholarship exists.” |
| Four non-polity cells all became inconclusive, showing the corpus fails outside states | **survives as negative evidence** | This weakens any claim to comprehensive world-history coverage but demonstrates that the method can represent non-polity uncertainty without forcing a false polity or false absence. A future scale test must improve sampling frames before claiming global completeness. |
| 15/25 inconclusive could mean the experiment is mostly an index of ignorance | **survives** | That is partly the tested value. Q6 shows that explicit, reasoned incompleteness is useful; but it also means a large future corpus would be research-intensive and should not be authorized merely from this pilot. |
| Mahdids failure is a geography-source defect, not slavery value | **survives** | Exactly. A coverage corpus can expose target-frame failures before they become historical claims. Do not count it as evidence for slavery or as proof the whole Cliopatria source is bad. |
| Maintaining coverage judgments could become expensive/stale | **park / next discriminating test** | This pilot does not establish sustainable maintenance at scale. Any next experiment should test update/reuse value versus curation cost, not simply research more places. |
| Positive result could be used to resurrect the Atlas application | **reject** | Nothing in COV-001 demonstrates value from Postgres, API, MapLibre or the old platform. The surviving form is a flat, auditable coverage corpus. |

## Adversary-adjusted material tasks

- Q1 — overview: **no / parity**
- Q2 — law vs practice: **material**
- Q3 — participation vs territorial inference: **material**
- Q4 — terminology/category query: **marginal; not counted**
- Q5 — global-handbook coverage: **material, bounded**
- Q6 — unresolved coverage/gaps: **material**

**Robust result: 4/6 material tasks.**

Mechanisms are genuinely different:
1. layer separation / prevention of inference substitution (Q2–Q3);
2. explicit research-coverage/gap state and reuse (Q5–Q6).

The numerical gate still passes after the adversarial downgrade.

## Adversarial conclusion

The experiment does **not** vindicate the Historical Slavery Atlas as an application.

It supports a smaller claim:

> A deliberately curated, explicit global coverage corpus can add practical value over narrative handbooks and a minimal ordinary matrix by making layer boundaries, handbook coverage judgments, abstentions and unresolved research directly reusable across place/time.

The artifact can be a flat table. That is the point.
