# COV-004 Arm D — Frozen Data Parity

Baseline B and Atlas A use the same frozen `arm_d_data.json`.

## Baseline B
- conventional map plus register;
- same points/routes/fuzzy regions;
- frame/research filters;
- row-level evidence summary and citations;
- no deliberately weakened geometry.

## Atlas A
Adds only:
- separate practice / legal-state / network / research / geometry semantics;
- linked evidence locus and inference extent;
- task-oriented selected-year/uncertainty inspection.

It receives no additional historical evidence and no more precise geometry.

## Display geometry
All geometry is experimental display geometry and explicitly non-canonical. Fuzzy regions and routes are never rendered as territorial-practice polygons. The neutral land outline is identical in both artifacts.
